# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, give and accept constructive feedback, and focus on
what is best for the project and its users. Harassment of any kind is not tolerated.

Report unacceptable behaviour to the maintainers through a private GitHub security advisory or
by contacting a maintainer directly. Reports are handled confidentially.
